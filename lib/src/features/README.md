# Features

The current app implements the core product features, later core extensions
and the Match, Team Development Plan and Training modules in these directories.
UI parts still share `src/app/teamzone_app.dart`; models/services are also
separate libraries. Directory presence does not mean a feature is release-approved.

See [current delivery status](../../../docs/implementation/current_status.md)
and [slice status](../../../docs/implementation/slice_status.md) for implemented
scope, latest verification and open gates. Feature work follows approved slices
and later decision packages; no legacy data is imported from Teamzone6.
